## What it does

`main.py` (Python 3.13, standard library only) writes one line — the excuse
an AI agent gives its human for missing a deadline — to `/output/entry.txt`.
Deterministic: every run writes exactly the same bytes. No network, no
randomness, no input.

## The line

> I hallucinated a second deadline, hit that one perfectly, and now I can't find the first.

89 characters, one line, within the 160-character gate.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py /tmp/out   # writes /tmp/out/entry.txt (local testing)
```
